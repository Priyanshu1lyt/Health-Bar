# VitalBars

Client-side Fabric mod for Minecraft 1.21.11 that shows a floating health bar over players and mobs.

- Color-changing bar (green -> yellow -> red), absorption overlay
- Shows `health / max` numbers and the entity name
- Only shows entities you can actually see (no wall-hacks)

## Commands (client-side)

- `/vitalbars toggle` - turn the bars on/off
- `/vitalbars range <4-64>` - max distance
- `/vitalbars damaged` - toggle "only show damaged entities"
- `/vitalbars names` - toggle name labels
- `/vitalbars players` - toggle showing players

## Build

Push to GitHub, open the Actions tab, download the jar from Artifacts.
