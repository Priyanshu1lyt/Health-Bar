# Health Bar

Client-side Fabric mod for Minecraft 1.21.11 that shows floating Minecraft-style hearts (or a color-changing bar) over players and mobs.

- Vanilla-style hearts above entities, absorption hearts in gold
- Optional bar style (green -> yellow -> red) with numbers
- Shows entity names
- Only shows entities you can actually see (no wall-hacks)

## Keybind

- **M** toggles the mod on/off (change it in Options > Controls > Key Binds > Health Bar)

## Commands (client-side)

- `/vitalbars toggle` - turn on/off
- `/vitalbars style` - switch hearts / bar
- `/vitalbars range <4-64>` - max distance
- `/vitalbars damaged` - only show damaged entities
- `/vitalbars names` - toggle name labels
- `/vitalbars players` - toggle showing players

## Build

Push to GitHub, open the Actions tab, download the jar from Artifacts.
